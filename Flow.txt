## 📊 **CLASS RELATIONSHIP SUMMARY**

### **Main Relationships:**
- **One-to-Many**: User → Favorites, User → Ratings, User → Reviews
- **One-to-Many**: Movie → Favorites, Movie → Ratings, Movie → Reviews  
- **Many-to-Many**: Users ↔ Movies (through Favorites/Ratings/Reviews)
- **Service Dependencies**: Controllers → Services → Repositories
- **Security Chain**: Filter → JWT Util → UserDetailsService → Database

### **Key Points:**
1. **User** can have multiple **Favorites**, **Ratings**, and **Reviews**
2. **Movie** can have multiple **Favorites**, **Ratings**, and **Reviews** from different users
3. **Services** handle business logic and coordinate between repositories
4. **Controllers** handle HTTP requests and responses
5. **Security** layer protects endpoints and manages authentication
